# Repository layout

This repository is the public DenyOut product tree: specs, examples, CLI/desktop code, and release artifacts.

| Path | Role |
| --- | --- |
| `cmd/` | CLI and desktop entrypoints |
| `internal/` | Library code |
| `docs/` | Product specification and guides |
| `examples/` | Fixtures and samples |
| `install.sh` | Linux/macOS installer |

Filter: keep what helps someone **install, understand, or verify** DenyOut.
