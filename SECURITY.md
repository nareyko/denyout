# Security

## Reporting

Do **not** open a public issue with real secrets or production URLs that still contain tokens.

- Prefer [GitHub Security Advisories](https://github.com/nareyko/denyout/security/advisories) on [`nareyko/denyout`](https://github.com/nareyko/denyout).
- Mailbox: `security@denyout.com` (forwarding live).

Use fake canaries from `examples/canaries/` for reproduction.
